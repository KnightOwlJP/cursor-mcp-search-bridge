プラント用ポンプ選定ガイドライン
====================================

第1章 概要
----------
プラント設計においてポンプの選定は、プロセス要件を満たしつつ経済性・信頼性・保守性を
総合的に評価して行う。本ガイドラインは遠心ポンプを中心に、選定の基本手順と留意事項を示す。

第2章 基本パラメータの決定
--------------------------
ポンプ選定の基本パラメータは以下の通りである。

- 必要流量（Q）: プロセス設計流量に対し10-15%のマージンを加算する
- 全揚程（H）: 静揚程＋摩擦損失揚程＋速度揚程＋制御弁差圧の合計
- NPSHa（有効吸込揚程）: 系統条件から算出し、NPSHr＋0.5m以上を確保
- 流体条件: 温度、粘度、密度、腐食性、固形物含有率

第3章 遠心ポンプの選定基準
--------------------------
比速度（Ns）に基づく羽根車形式の選定:
- Ns < 300: 渦巻型（Volute type）— 低流量・高揚程用途
- Ns 300-600: ディフューザ型 — 中流量・中揚程用途
- Ns > 600: 斜流・軸流型 — 高流量・低揚程用途

材質選定は流体の腐食性に基づき、以下を基本とする:
- 清水・低温: FC200（鋳鉄）
- 弱腐食性: SCS13（ステンレス鋳鋼）
- 強腐食性: SCS16（SUS316相当）またはハステロイ
- スラリー: 高クロム鋳鉄またはゴムライニング

第4章 配置と運転条件
--------------------
- 据付: 自吸式でない場合、ポンプ中心は液面以下に設置（水没式を推奨）
- 予備機: 重要系統は1+1構成、一般系統は共用予備可
- 運転範囲: BEP（最高効率点）の70-120%で使用
- 最小流量: ミニマムフロー弁を設置し、締切運転を防止
- シール: メカニカルシール（API 682準拠）を標準、高温はダブルシール

第5章 試験・検査
----------------
- 工場試験: API 610に基づく性能試験（流量-揚程曲線、NPSH試験）
- 現場試験: 据付後の振動測定（API 610許容値以下を確認）
- 定期検査: 年1回の振動・軸受温度測定、3-5年ごとの分解点検
