## リスクと対策

| リスク | 影響度 | 発生確率 | 対策 |
|--------|--------|----------|------|
| Azure OpenAI のレスポンス遅延 | 中 | 中 | キャッシュ導入、タイムアウト設定 |
| 社内APIの仕様変更 | 高 | 低 | API バージョニング、アダプタパターン |
| ユーザー採用率の低さ | 高 | 中 | 早期ユーザー参画、トレーニング充実 |
| セキュリティ要件の変更 | 中 | 中 | 柔軟なアーキテクチャ、定期レビュー |
| Cursor/MCP のバージョンアップ | 低 | 高 | 互換性テストのCI組込み |
